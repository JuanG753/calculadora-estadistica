Recetario de Fórmulas Oculto
1. Pruebas de Medias
Z0 (Poblacional):
Z =
(X̄₁ - X̄₂) - (μ₁ - μ₂) √ (σ₁²/n₁ + σ₂²/n₂)
T0 (Muestral):
t =
(X̄₁ - X̄₂) - (μ₁ - μ₂) √ (S₁²/n₁ + S₂²/n₂)

df = n₁ + n₂ - 2
2. Pruebas de Varianzas
Chi-Cuadrada (1 Pob): χ²₀ = (n - 1)S² / σ₀²
Fisher F (2 Pob):
F₀ =
(S₁² / S₂²) (σ₁² / σ₂²)
3. Potencia y Tamaño de Muestra
Valor Crítico (Vc):
Vc = μ₀ + Z_α * √ (σ₁²/n₁ + σ₂²/n₂)
Potencia (1 - β):
Z_β =
(Vc - μ₁) √ (σ₁²/n₁ + σ₂²/n₂)
Cálculo de 'n' (muestras iguales):
n =
(Z_α - Z_β)² * (σ₁² + σ₂²) (μ₁ - μ₀)²
4. Tabla ANOVA (SCT, SCE)
SCT (Tratamientos): Σ n_i (Ȳ_i. - Ȳ_..)²
df = k - 1
SCE (Error): Σ Σ (Y_ij - Ȳ_i.)²
df = N - k
SST (Total): Σ Σ (Y_ij - Ȳ_..)²
df = N - 1
Cuadrados Medios: CM_T = SCT / df_T   |   CM_E = SCE / df_E
F₀ Calculada = CM_T / CM_E
5. Supuestos ANOVA
Aleatoriedad (Rachas):
μ_R =
2n₁n₂ n₁ + n₂
+ 1

σ²_R =
2n₁n₂(2n₁n₂ - n₁ - n₂) (n₁ + n₂)²(n₁ + n₂ - 1)


Z₀ = (R - μ_R) / σ_R
Normalidad (Jarque-Bera):
JB = (n / 6) * [ Sesgo² + (CurtosisExceso² / 4) ]
Normalidad (D'Agostino K²):
K² = Z(Sesgo)² + Z(Curtosis)²
Homocedasticidad (Bartlett):
χ²₀ =
(N-k)ln(S²_p) - Σ(n_i - 1)ln(S²_i) 1 + [1 / 3(k-1)] * [Σ(1/(n_i-1)) - 1/(N-k)]
